# 比赛要求（【华为openJiuwen】基于JiuwenSwarm的Agent金融分析报告生成）

> 来源：息壤竞赛平台 https://www.xir.cn/competition/1166 及本地 `要求.md`

## 赛题任务

参赛队伍需基于 openJiuwen 框架开发一个能够自主完成金融分析的智能体。该 Agent 须在组委会指定的上市公司范围内进行选择决策，并给出相应的仓位配置方案。作品验证期开始前，各队伍需提交最终的投资组合结果（含上市公司代码及持仓占比），Agent 可根据自身判断选择满仓、半仓乃至完全空仓。

- **初赛**：基于投资组合表现过滤表现较差的队伍，并根据报告生成质量评选队伍进入决赛（仅依据收益率及风险控制指标客观排名）
- **决赛**：重点考察投资报告的完整性、逻辑严谨性与答辩表现

## 关键约束

1. **框架强制性**：Agent 实现必须深度耦合 openJiuwen 框架核心能力模块，不得使用未经封装的独立脚本绕过框架约束
2. **投资标的限定**：严格限定于组委会公布的上市公司列表；允许空仓，但须在报告中阐明决策逻辑
3. **报告分析维度**：技术分析、基本面分析、宏观经济分析、另类数据挖掘、情绪因子构建等
4. **成果可复现性**：第三方可依据代码与环境说明完整复现投资决策过程及资源消耗数据

## 提交格式（参考 example/）

- `Portfolio.json`：`{"股票代码": 持仓占比}`
- `个股投资研报/{股票代码}.md`
