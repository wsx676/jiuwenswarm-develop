# 选股资料库（info）

本目录为【华为openJiuwen】基于JiuwenSwarm的Agent金融分析报告生成赛题整理的选股参考资料。

- 比赛入口：https://www.xir.cn/competition/1166
- 公司池：`example/上市公司列表.xlsx`（六大板块、49 家 A 股，详见 00_比赛要求.md）
- 资料搜集日期：2026-08-15（网络公开信息，均附来源链接，使用前需核实最新数据）

## 目录结构

| 文件 | 内容 |
|------|------|
| 00_比赛要求.md | 赛题任务、提交格式、评分维度、公司池清单 |
| 01_宏观与政策.md | 宏观经济指标、财政/货币政策取向、对板块的影响映射 |
| 02_板块_金融.md | 银行/保险/证券投资逻辑与个股资料 |
| 03_板块_消费.md | 白酒/家电/食品/免税投资逻辑与个股资料 |
| 04_板块_新能源电力.md | 锂电/光伏/电力投资逻辑与个股资料 |
| 05_板块_科技AI半导体.md | 算力/光模块/半导体/存储投资逻辑与个股资料 |
| 06_板块_周期资源.md | 黄金/铜/化工/能源投资逻辑与个股资料 |
| 07_板块_高端制造基建.md | 工程机械/轨交/建筑投资逻辑与个股资料 |
| 08_选股线索汇总.md | 全池候选评级线索与组合配置建议 |

## 使用说明

1. 所有数据点均标注了来源链接，符合赛题"事实溯源"与"成果可复现"要求；
2. 搜索快照存在时效性，正式生成报告前应由 Agent 的新闻采集器（Deep Research）刷新最新信息；
3. 资料仅供 Agent 研发与报告生成参考，不构成投资建议。
