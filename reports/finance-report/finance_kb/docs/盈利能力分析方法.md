# 盈利能力分析方法

## 核心指标
毛利率、净利率、ROE、ROA，须观察至少 8 个报告期的趋势而非单点值。

## 分析步骤
1. 毛利率趋势：判断产品竞争力与定价权；毛利率逆势提升需验证是否由产品结构升级或原材料降价驱动。
2. 费用率拆解：销售/管理/研发费用率的变化方向，销售费用率骤增可能预示需求走弱。
3. 净利率与毛利率的缺口：缺口扩大说明费用或非经常损益侵蚀，需排查一次性收益。
4. ROE 质量：结合杜邦分解判断来源；扣非 ROE 与 ROE 差距过大提示利润依赖非经常项目。

## 常见陷阱
- 单季度高增长可能是低基数效应，须看两年复合增速。
- 毛利率高于同业过多需验证商业模式的可持续性。
