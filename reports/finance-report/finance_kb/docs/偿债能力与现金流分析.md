# 偿债能力与现金流分析

## 偿债指标
- 资产负债率：行业可比口径下判断，金融业天然高杠杆不可跨行业比较。
- 流动比率/速动比率：<1 提示短期偿债压力，但要结合经营性现金流判断。
- 利息保障倍数：<3 时偿债压力显著。

## 现金流质量
- 经营现金流净额 / 净利润 ≥ 1 为利润含金量高的标志；长期 <1 警惕利润"纸面化"。
- 自由现金流 = 经营现金流 − 资本开支，持续为正才具备分红与回购能力。
- 收现比（销售商品收到的现金 / 营业收入）≈ 1 + 税率水平为正常，明显偏低提示应收堆积。

## 风险提示
有息负债快速攀升叠加经营现金流转负，是信用风险的领先信号。
