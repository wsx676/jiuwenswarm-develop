### 3.1 🟥 **致命差距：缺行业 + 宏观两类研报**

**影响**：决赛评分"投资报告完整性"直接扣分；portfolio 评审时若评审要看不同维度报告，直接空白。

**修复路径**：

- 已在 README 用法中演示 `industry`/`macro` 调用方式，但**从未真正产出过报告**

### 3.2 🟥 **致命差距：Portfolio 半仓未阐明理由**

**赛题要求**：满仓、半仓、完全空仓均可，但**须在报告中阐明决策逻辑**

**项目状态**：Portfolio 8 只标的权重和 = **0.77（半仓）**，决策日志 `empty_reason` 为空字符串。

```json
// 当前 Portfolio.json
{
  "603986": 0.14, "601168": 0.13, "601899": 0.13, "300750": 0.12,
  "600426": 0.12, "300308": 0.12, "600309": 0.12, "601600": 0.11
}
// 权重和 = 0.77（半仓）
```

`decision.json` 的 `empty_reason` 是空字符串，但 `empty_position=false`，**逻辑上不报 empty_reason 也对**。问题是**没有任何文件说明为何半仓而非满仓**——这是赛题明确要求的"决策逻辑阐明"。

**修复路径**：
- 在 `decision.json` 增加 `position_decision: "half"` 字段
- 增加 `position_rationale: "当前 8 只标的平均分 73 分，剩余 38 只标的评分低于 60 分阈值未达入选门槛，按规则不强制满仓；保留 23% 现金应对宏观波动"` 字段
- 在 README/portfolio 报告里同步说明

## 四、🟡 中等差距（影响评分但非一票否决）

### 4.1 标的池覆盖广度不足

**现状**：Portfolio 仅 8 只标的（出自 1 次跑批），未覆盖六大板块的均衡配置。

**问题**：6 大板块（消费/医药/科技/金融/能源/制造）应至少每个板块有 1-2 只候选入榜，**当前缺失**：
- 医药板块：恒瑞医药 (600276) 等
- 金融板块：招商银行 (600036) 等
- 制造板块：三一重工 (600031) 等
- 能源板块：中国石化 (600028) 等

**影响**：评审会认为"分散度不足 + 板块集中度过高"，直接影响 C5「风险控制指标」。

**修复路径**：
- 提高 `max_positions` 默认值（如 12-15）
- 增加「板块分散度」硬约束（每个板块至少 N% 权重上限）
- 在 `_allocate` 增加板块维度约束

### 4.2 缺少"情绪因子"与"另类数据"

**赛题要求**："可综合运用...另类数据挖掘、情绪因子构建"

**现状**：
- 已有新闻情绪打分（在研报中"消费板块情绪得分 25 分"）
- 但**未单独形成"情绪因子"权重项**
- 暂无"另类数据"（如雪球讨论度、龙虎榜、融资融券、北向资金、ESG 评分）

**修复路径**：
- 在 `score_research` 因子表中增加「情绪因子」一项（10 分权重）
- 增加北向资金、龙虎榜数据采集器（可用 akshare）
- 在 README/参赛说明中明示这些因子维度

### 4.3 run_stats.json 含 0 calls 的早期记录

**现状**：第一次跑批 `calls=0`（说明早期跑批未配 LLM Key），后续跑批恢复 LLM。

**问题**：组委会复现验证时若取**最早一次**记录，看到 0 calls 可能误判"未真实跑通"。

**修复路径**：
- 在 `README.md` 明确指出"复现时应看最新一次 run，或删旧记录后重跑"
- 或者：在 README 标注 "本目录 `decision_log/run_stats.json` 是历史累计，最新批次见 `runs[-1]`"

### 4.4 评分模型过于依赖历史财报口径

**现状**：因子打分主要看 ROE/毛利率/PE/同比增速，**缺前瞻性指标**（如一致预期 EPS 变化、未来 12 个月盈利预测）。

**影响**：在初赛评测期（**8/25-9/21**，20 个交易日）只有真实行情收益是客观的，**模型对中短期行情的解释力不足**。

**修复路径**：
- 增加动量因子（近 5/10/20 日涨幅）
- 增加相对强度（标的 vs 板块 vs 大盘）
- 减少财务质量因子的权重（财报数据滞后性强）

### 4.5 引用率 ≥ 90% 闸门未在 README 中明示

**赛题隐含**（基于评分细则文档中"报告生成质量"）：高质量报告须标注数据来源

**现状**：研报中每段都有"数据来源：xxx"，但 README 没明示引用率口径。

**修复路径**：README 加一行说明：本项目 `CitationChecker` 强制引用率 ≥ 90%。
