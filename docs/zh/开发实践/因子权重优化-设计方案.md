# 因子权重优化（动量 + 情绪）— 设计方案

> **目标**：为 CCF BDCI 2026 初赛提升收益率与风险控制表现，落地赛题明确要求的「技术分析 / 情绪因子」。
> **依据**：`docs/zh/开发实践/CCF-BDCI-2026-JiuwenSwarm-差距评审.md`「分析维度」差距 + `InvestorAgent.score_research` 当前缺情绪因子。
> **决策**（经 /sc:brainstorm 确认）：纯现有数据 / 多窗口+波动+相对强度 / 复用现有情绪逻辑 / vs 板块均值 / 核实+规则降级 / 改码+测试+对比。
> **评审修订**（2026-08-20）：修复 3 个评审发现的问题——①动量方向算反 ②sentiment 字段 100% 空 ③period_return 是 1 年口径。详见「八、评审修订记录」。

## 一、现状与差距

### 1.1 当前 `score_research`（investor.py:76-140）

| 维度 | 权重 | 子指标 |
|------|------|--------|
| 财务质量 | 25 | ROE/毛利率/资产负债率 |
| 成长性 | 20 | 营收/净利同比 |
| 估值 | 20 | PE |
| 动量 | 15 | 仅 `period_return`（1 个指标） |
| 情绪 | **0** | **完全没有** |
| 风控 | 20 | 数据完整性/现金流/风险信号 |
| **合计** | **100** | |

### 1.2 差距

1. **动量**：只用单一 `period_return`，未拆窗口、无波动率、无相对强度 → 对初赛收益率排名贡献弱
2. **情绪**：赛题明确要求「情绪因子构建」，但打分中为 0（情绪只在研报里展示，不进决策）
3. **权重结构**：基本面（财务+成长+估值=65）占绝对主导，对中短期行情反应滞后

## 二、数据可用性验证（评审修订后）

### 2.1 ⚠️ 关键事实：`records` 是升序存储

`quote.records` 按**日期升序**：`r[0]` 最早（如 2025-08-18），`r[-1]` 最新（如 2026-08-14）。

**动量计算必须从尾部（最新）算起**，否则方向全反。

### 2.2 多窗口动量（正确口径，实测）

| 指标 | 正确计算 | 茅台实测 |
|------|---------|---------|
| 5 日动量 | `(close[-1] - close[-6]) / close[-6] * 100` | **+2.50%** |
| 20 日动量 | `(close[-1] - close[-21]) / close[-21] * 100` | **+7.10%** |
| 60 日动量 | `(close[-1] - close[-61]) / close[-61] * 100` | **+4.60%** |
| 20 日波动率 | `change_pct` 近 20 日标准差 | **0.71%** |

消费板块多标的对比（相对强度素材，mom 均为正确口径）：
| 代码 | 名称 | mom5 | mom20 | 近1年 period_return | vol |
|------|------|------|-------|--------------|-----|
| 600519 | 贵州茅台 | +0.7% | +7.1% | -2.51% | 0.71% |
| 000858 | 五粮液 | -5.0% | +2.4% | **-38.82%** | 1.02% |
| 600887 | 伊利股份 | -1.1% | +0.6% | -2.29% | 0.85% |
| 603288 | 海天味业 | -1.1% | -0.4% | -6.69% | 1.00% |
| 000333 | 美的集团 | +0.8% | +4.3% | **+22.15%** | 0.82% |

> **重要**：`period_return` 是**整个 records 区间的收益率（约 1 年）**，不是特定窗口。五粮液近 1 年 -38.82% 但近 20 日 +2.4% → **相对强度绝不能用它，须统一用 mom20 口径**。

### 2.3 情绪数据（实测：`sentiment` 字段 100% 空）

- `news_collector.py:45` 定义了 `sentiment: str = ""` 字段，但**从未赋值**
- 实测：茅台 21 条、美的 37 条新闻，`sentiment` 字段**全部为空**（填充率 0%）
- `industry_analyzer.py:29-42` 已有现成词表：`POSITIVE_WORDS`（20 词）/ `NEGATIVE_WORDS`（19 词）/ `POLICY_WORDS`（10 词）

> **结论**：情绪因子**直接复用词表规则**，不依赖死字段 `sentiment`。

## 三、新因子模型

### 3.1 权重分配（总分 100 不变）

| 维度 | 旧 | 新 | 变化 | 说明 |
|------|-----|-----|------|------|
| 财务质量 | 25 | **20** | -5 | 基本面锚，保底 |
| 成长性 | 20 | **15** | -5 | 财报滞后，降权 |
| 估值 | 20 | **15** | -5 | 同上 |
| **动量** | 15 | **25** | **+10** | 初赛排名核心抓手 |
| **情绪** | 0 | **10** | **+10** | 赛题明确要求 |
| 风控 | 20 | **15** | -5 | 让位给情绪 |
| **合计** | 100 | **100** | 0 | 约束不变 |

> **核心逻辑**：动量(25)+情绪(10) 捕捉中短期趋势（初赛按收益率排名）；基本面(35) 保底防回撤。

### 3.2 动量子因子（25 分）

| 子因子 | 权重 | 正确计算 | 评分规则 |
|--------|------|---------|---------|
| 短期动量 | 7 | 5 日涨跌幅（尾端算） | ≥+3%→7; ≥0→4; ≥-5%→2; 否则 0 |
| 中期动量 | 8 | 20 日涨跌幅（尾端算） | ≥+8%→8; ≥0→5; ≥-8%→2; 否则 0 |
| 长期动量 | 5 | 60 日涨跌幅（尾端算） | ≥+15%→5; ≥0→3; ≥-10%→1; 否则 0 |
| 低波动 | 3 | 20 日 change_pct 标准差 | ≤1.0%→3; ≤1.5%→2; ≤2.5%→1; 否则 0 |
| 相对强度 | 2 | 标的 mom20 - 板块 mom20 均值 | 跑赢→2; 持平(±1%)→1; 跑输→0 |

### 3.3 情绪子因子（10 分，复用词表，不依赖 sentiment 字段）

| 子因子 | 权重 | 计算 | 评分规则 |
|--------|------|------|---------|
| 情绪方向 | 6 | `(pos - neg) / max(n,1)`（词表命中归一化） | >0→6; =0→3; <0→0 |
| 情绪强度 | 2 | 有效新闻条数 n | ≥10→2; ≥5→1; 否则 0 |
| 情绪一致性 | 2 | 正负占比差 | pos>neg+0.2→2; 均衡→1; 负显著→0 |

### 4.2 `investor.py` 新增方法（正确版）

```python
# 情绪词表复用 industry_analyzer（避免重复定义，模块级 import 或内置副本）
_POSITIVE_WORDS = ("增长", "超预期", "新高", "提价", "回暖", "复苏", "利好",
                   "中标", "回购", "增持", "分红", "扩张", "景气", "突破",
                   "加速", "净流入", "创新高", "景气度", "消费提振")
_NEGATIVE_WORDS = ("下滑", "低于预期", "降价", "处罚", "调查", "亏损", "减持",
                   "质押", "风险", "召回", "退市", "下跌", "放缓", "承压",
                   "监管", "警告", "疲软", "累库", "价格战")

def _momentum_score(self, quote: dict, sector_avg_mom20: float = 0.0) -> float:
    """多窗口动量打分（25 分：5/20/60 日动量 + 波动率 + 相对强度）

    关键：records 升序（r[-1] 最新），动量从尾部计算。
    """
    records = quote.get("records", []) or []
    if len(records) < 21:
        return 0.0  # 数据不足不给分（需至少 21 条算 20 日动量）
    close = [r["close"] for r in records]
    latest = close[-1]
    mom5  = (latest - close[-6]) / close[-6] * 100
    mom20 = (latest - close[-21]) / close[-21] * 100
    mom60 = ((latest - close[-61]) / close[-61] * 100
             if len(close) > 61 else mom20)  # <62 条时用 20 日替代
    import statistics
    vol = statistics.stdev(
        [abs(r["change_pct"]) for r in records[-20:]])
    rel = mom20 - sector_avg_mom20  # 相对强度：统一 20 日口径
    score = 0.0
    score += 7 if mom5 >= 3 else (4 if mom5 >= 0 else (2 if mom5 >= -5 else 0))
    score += 8 if mom20 >= 8 else (5 if mom20 >= 0 else (2 if mom20 >= -8 else 0))
    score += 5 if mom60 >= 15 else (3 if mom60 >= 0 else (1 if mom60 >= -10 else 0))
    score += 3 if vol <= 1.0 else (2 if vol <= 1.5 else (1 if vol <= 2.5 else 0))
    score += 2 if rel > 1 else (1 if rel >= -1 else 0)
    return min(25.0, score)

def _sentiment_score(self, news_data: dict) -> float:
    """情绪打分（10 分，复用词表规则，不依赖 sentiment 字段）

    sentiment 字段当前 100% 空（news_collector 未赋值），
    直接用标题+摘要做正负词表命中统计（与 industry_analyzer 同口径）。
    """
    items = news_data.get("items", []) or []
    if not items:
        return 0.0
    text = " ".join(
        f"{it.get('title', '')} {it.get('summary', '')}" for it in items)
    pos = sum(text.count(w) for w in _POSITIVE_WORDS)
    neg = sum(text.count(w) for w in _NEGATIVE_WORDS)
    n = len(items)
    net = (pos - neg) / max(n, 1)  # 归一化到 [-inf, inf]，符号即方向
    score = 6.0 if net > 0 else (3.0 if net == 0 else 0.0)
    score += 2.0 if n >= 10 else (1.0 if n >= 5 else 0.0)
    pos_ratio = pos / max(n, 1)
    neg_ratio = neg / max(n, 1)
    score += 2.0 if pos_ratio > neg_ratio + 0.2 else (
        1.0 if abs(pos_ratio - neg_ratio) <= 0.2 else 0.0)
    return min(10.0, score)
```

### 4.3 `score_research()` 改造

```python
def score_research(self, research_data: dict) -> float:
    """因子打分（0-100，确定性规则，成果可复现）

    因子与权重（总分 100）：
    - 财务质量 20：ROE/毛利率/资产负债率
    - 成长性   15：营收/净利润同比
    - 估值     15：PE 合理性
    - 动量     25：5/20/60 日动量 + 波动率 + 相对强度
    - 情绪     10：新闻正负词表命中（复用 industry_analyzer 口径）
    - 风控     15：数据完整性/现金流质量/风险信号
    """
    finance = research_data.get("finance_analysis")
    quote = research_data.get("quote_data", {}) or {}
    news = research_data.get("news_data", {}) or {}
    sector_avg_mom20 = research_data.get("sector_avg_mom20", 0.0)

    score = 0.0

    # 1. 财务质量（盈利能力 + 偿债安全）—— 权重 25→20，缩比
    prof = getattr(finance, "profitability", None) or {}
    solvency = getattr(finance, "solvency", None) or {}
    roe = prof.get("roe")
    if roe is not None:
        score += 8 if roe >= 15 else (5 if roe >= 8 else (3 if roe > 0 else 0))
    gross = prof.get("gross_margin")
    if gross is not None:
        score += 7 if gross >= 40 else (4 if gross >= 20 else 2)
    debt = solvency.get("debt_ratio")
    if debt is not None:
        score += 5 if debt <= 40 else (3 if debt <= 60 else 1)

    # 2. 成长性（同比口径）—— 权重 20→15，缩比
    growth = getattr(finance, "growth", None) or {}
    rev_g = growth.get("revenue_growth")
    if rev_g is not None:
        score += 8 if rev_g >= 15 else (5 if rev_g >= 5 else (2 if rev_g >= 0 else 0))
    np_g = growth.get("net_profit_growth")
    if np_g is not None:
        score += 7 if np_g >= 15 else (4 if np_g >= 5 else (2 if np_g >= 0 else 0))

    # 3. 估值（PE 年化口径）—— 权重 20→15，缩比
    pe = (getattr(finance, "valuation", None) or {}).get("pe")
    if pe is not None:
        if pe <= 0:
            score += 0
        elif pe <= 25:
            score += 15
        elif pe <= 40:
            score += 9
        elif pe <= 60:
            score += 4

    # 4. 动量（多窗口 + 波动 + 相对强度）—— 权重 15→25
    score += self._momentum_score(quote, sector_avg_mom20)

    # 5. 情绪（词表规则）—— 新增 10
    score += self._sentiment_score(news)

    # 6. 风控与数据质量 —— 权重 20→15，缩比
    if finance is not None and quote:
        score += 7
    cf = solvency.get("cashflow_to_profit")
    if cf is not None:
        score += 5 if cf >= 0.8 else (3 if cf >= 0 else 0)
    if finance is not None:
        risk_hits = research_data.get("risk_signals") or []
        score += 3 if not risk_hits else max(0, 3 - 2 * len(risk_hits))

    return round(min(100.0, score), 1)
```

### 4.4 板块 mom20 均值预扫（相对强度数据源）

`run_portfolio` / `score_pool` 在逐标的评分前，预扫板块内各标的 mom20 算均值：

```python
# run_portfolio 内（scores 实时计算分支）
def _sector_mom20_avg(pool, research_fn) -> dict:
    """板块名 → mom20 均值（预扫缓存）"""
    avg = {}
    for sector, items in pool.items():
        moms = []
        for symbol, name in items:
            data = research_fn(symbol, name)
            q = (data.get("quote_data") or {})
            r = q.get("records") or []
            if len(r) > 21:
                c = [x["close"] for x in r]
                moms.append((c[-1] - c[-21]) / c[-21] * 100)
        avg[sector] = sum(moms) / len(moms) if moms else 0.0
    return avg

sector_avgs = _sector_mom20_avg(pool, research_fn)
# 逐标的评分时注入
research_data["sector_avg_mom20"] = sector_avgs.get(sector, 0.0)
```

> **注意**：预扫会多一次 research_fn 调用（缓存命中代价低）。`scores` 缓存分支（`--use-cached-scores`）无法重算板块均值 → 相对强度在该路径降级为 `sector_avg_mom20=0`（只影响 2 分，可接受）。

class TestMomentumFactor:
    def _quote_with_trend(self, ups: int, downs: int):
        """构造升序 records：先跌 downs 天再涨 ups 天，验证尾端动量"""
        records = []
        price = 100.0
        for _ in range(downs):
            price *= 0.98; records.append({"close": price, "change_pct": -2.0})
        for _ in range(ups):
            price *= 1.02; records.append({"close": price, "change_pct": 2.0})
        return {"records": records}

    def test_rising_tail_high_score(self):
        # 尾部上涨序列 → 动量高分
        quote = self._quote_with_trend(ups=25, downs=5)
        assert InvestorAgent({})._momentum_score(quote, 0.0) >= 15

    def test_falling_tail_low_score(self):
        quote = self._quote_with_trend(ups=5, downs=25)  # 尾部下跌
        assert InvestorAgent({})._momentum_score(quote, 0.0) <= 8

    def test_insufficient_data_zero(self):
        assert InvestorAgent({})._momentum_score({"records": []}, 0.0) == 0.0

    def test_relative_strength_vs_sector(self):
        # 标的 mom20=+8 vs 板块均值 +2 → 相对强度 2 分
        inv = InvestorAgent({})
        base = inv._momentum_score(self._quote_with_trend(25, 5), 0.0)
        strong = inv._momentum_score(self._quote_with_trend(25, 5), -5.0)
        assert strong >= base  # 板块均值越低, 相对强度越高

## 六、风险与对策

| 风险 | 影响 | 对策 |
|------|------|------|
| **R1** `period_return` 口径与多窗口不一致 | 相对强度失真 | 动量/相对强度**全用 records 自算**，不依赖 period_return |
| **R2** news `sentiment` 字段 100% 空 | 情绪因子依赖死字段 | 直接用词表规则（POSITIVE/NEGATIVE_WORDS），不读 sentiment 字段 |
| **R3** 板块均值预扫多一次采集 | 性能下降 | 缓存命中代价低；`--use-cached-scores` 路径降级 rel=0 |
| **R4** 权重改动影响入选标的 | 组合变化大 | 新旧对比验证后再定；保守可只调动量(15→20)、情绪(0→5)小步 |
| **R5** records < 21 条的标的不给动量分 | 次新股不公平 | 数据不足返回 0（风控优先，不硬凑） |
| **R6** 60 日动量数据不足 | 长期动量缺失 | `<62` 条时用 20 日动量替代（降级不缺失） |
