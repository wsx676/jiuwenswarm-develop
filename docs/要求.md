赛题名称
【华为openJiuwen】基于JiuwenSwarm的Agent金融分析报告生成

赛题任务
参赛队伍需基于 openJiuwen 框架开发一个能够自主完成金融分析的智能体。该 Agent 须在组委会指定的上市公司范围内进行选择决策，并给出相应的仓位配置方案。作品验证期开始前，各队伍需提交最终的投资组合结果（含上市公司代码及持仓占比），Agent 可根据自身判断选择满仓、半仓乃至完全空仓。初赛基于投资组合表现过滤表现较差的队伍，并根据报告生成质量评选队伍进入决赛，决赛则结合投资报告的完成度进行综合评判。

比赛要求
框架强制性：Agent 的实现必须深度耦合 openJiuwen 框架的核心能力模块，不得使用未经封装的独立脚本绕过框架约束。
投资标的限定：选择范围严格限定于赛事组委会公布的上市公司列表，Agent 可依据自身策略自主决定持仓上市公司及仓位权重；若判定上市公司列表内所有标的在评测期内均不具备投资价值，允许保持空仓，但须在报告中阐明决策逻辑。
报告分析维度：金融分析报告应包含充分的分析过程，可综合运用技术分析、基本面分析、宏观经济分析、另类数据挖掘、情绪因子构建等参赛者认为合理的方法论。初赛阶段，仅依据收益率及风险控制指标进行客观排名并确定晋级名单；决赛阶段，则重点考察投资报告的完整性、逻辑严谨性与答辩表现。
成果可复现性：最终提交材料须确保第三方可依据所提供代码与环境说明完整复现投资决策过程及资源消耗数据。
